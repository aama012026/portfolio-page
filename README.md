# portfolio-page
This project is my portfolio page, served with bun.

- Scripts written in [TS](https://www.typescriptlang.org/).
- FE/Reactivity via [data-star](https://data-star.dev/).
- Code highlighting via [prismjs](https://prismjs.com/).

---

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run server.ts
```
